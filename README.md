# ❤️ UsOnMap – Forever Connected

**UsOnMap** is a private couple connection app designed to help two people stay connected through secure chat, anniversary memories, and consent-based live location sharing.

Developed with Flutter and Firebase.

## ✨ Features

- 🔐 Secure user authentication
- ❤️ Private couple connection
- 💬 Personal chat
- 📍 Consent-based live location sharing
- 🗺️ OpenStreetMap integration
- 🔋 Battery status sharing
- 💝 Anniversary countdown
- 🌙 Light and Dark themes
- 🔔 Push notification support (FCM)

## 🛠️ Technologies Used

- Flutter & Dart
- Firebase Authentication
- Cloud Firestore
- Firebase Cloud Messaging
- OpenStreetMap
- Flutter Map
- Geolocator

## 🚀 Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or Visual Studio Code
- A Firebase project

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Ramnase94/usonmap-flutter-app.git
   ```

2. Open the project folder:

   ```bash
   cd usonmap-flutter-app
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Configure your Firebase project using FlutterFire CLI.

5. Create your local private configuration file from the example:

   ```bash
   # Copy lib/private_config.example.dart
   # to lib/private_config.dart
   ```

6. Add your own configuration values to the local file.

7. Run the application:

   ```bash
   flutter run
   ```

## 🔒 Security & Privacy

- Location sharing is intended to be consent-based.
- Private configuration files and Firebase configuration files are excluded from this public repository.
- Never upload private keys, service-account credentials, or personal configuration files.
- Configure Firebase Security Rules before using the app.
